# Sakura Wars 1 — Dreamcast English Translation

**An independent English translation project for Sakura Wars (Sakura Taisen) on Sega Dreamcast.**

**Translation: 100% complete — Beta Coming Soon!**

## About the Project

I'm currently working on a full English translation of the original Sakura Wars for Sega Dreamcast.

Some of you may already know me from my Sakura Wars 4 English translation project for Dreamcast.

I'm happy to announce that **all of the Japanese text in Sakura Wars 1 has now been translated into English!**

The project is currently approaching its Beta testing phase.

## Translation Information

This is an **independent AI-assisted English translation** created from the original Japanese Dreamcast game.

**This project does NOT use, copy or port the existing Sega Saturn English fan translation.**

I respect the work of the Saturn fan translation team and have not reused their translation.

AI-assisted translation has been used to translate the original Japanese text into English.

Although the translation is complete, some dialogue may still require contextual corrections, proofreading and polishing during Beta testing.

## What Is Translated?

The English translation covers the game's text, including:

- Main story dialogue
- Character conversations and events
- LIPS dialogue choices
- Menus and interface
- Battle-related text
- Character information
- System messages
- Other in-game text

All text has been translated, but full gameplay testing is still required.
